插入特殊符号（Word）

键盘快捷键
  • Ctrl+Alt+1 打开面板 / Ctrl+Alt+2 关闭面板
  • Ctrl+Alt+D 插入日期 / P 导出 PDF（Word+Excel）
  • Ctrl+Alt+B 加粗 / I 斜体 / U 下划线
  • Ctrl+Alt+J 标题1（Word）/ L 项目符号 / N 编号
  • Ctrl+Alt+C 居中 / H 突出显示 / K 清除格式
  • Ctrl+Alt+W 字数统计（Word）/ Shift+U 大写（Word）
  • Ctrl+Alt+Q 循环填充色（Excel）/ A 自动调整 / T 去空格
  • Ctrl+Alt+F 冻结首行 / Shift+F 取消冻结
  • Ctrl+Alt+R 插入行 / S 求和 / E 升序
  • Ctrl+Alt+G 生成图表 / X 清除内容 / Y 按颜色求和
  • Ctrl+Alt+M 合并单元格（Excel）

Mac 对应修饰键：Ctrl+Alt → Command+Option。未列出的命令可在上方搜索后点击执行。
